# Requirements

- Resolve Wiki links to their underlying resource token and route Sheets, Base, and Docx correctly.
- Read and write ordinary spreadsheets and Base records with typed Mastra tools.
- Support first empty cell under a header, row append, explicit cell update, unique row or record match, Base create and update.
- Preflight edit permission, ask before switching from app to user identity, keep OAuth scope state, and require one persistent write approval.
- Preserve existing calendar, task, document, group, and gateway behavior.
- Verify with mocked Feishu APIs, typecheck, tests, and Mastra build. Live private deployment verification depends on application scopes and collaborator access.
